# Econ Wordle

A collection of ten Wordle-style puzzles about landlocked countries, with a focus on Nepal. Created for a school economics presentation in 2024 using HTML, CSS, and JavaScript.

[Play the demo](https://econ-wordle.vercel.app/)

## Run locally

No package installation or build step is required. With Python 3 installed:

```sh
git clone https://github.com/c-jien/EconWordle.git
cd EconWordle
python3 -m http.server 8000
```

Open <http://localhost:8000> in your browser. The landing page links to the game.

## Files

- `index.html` — introduction and game entry point
- `game.html` — game screen
- `script.js` — puzzle data and game interaction
- `styles.css` — shared styles

This is a small educational project; the puzzle set is fixed and it is not affiliated with the official Wordle game.
